# Portfólio - Vinícius dos Santos Ribeiro Antunes

Este projeto foi desenvolvido durante o curso Técnico em Desenvolvimento de Sistemas do SENAI.

## Sobre o projeto

O objetivo deste projeto é criar uma página de portfólio utilizando HTML5, apresentando informações pessoais, habilidades, projetos desenvolvidos e uma área de contato.

## Tecnologias utilizadas

- HTML5
- Estrutura semântica
- Formulários HTML
- Tabelas
- Links e navegação interna

## Funcionalidades

- Apresentação pessoal
- Foto de perfil
- Lista de habilidades
- Tabela com projetos
- Links para projetos no GitHub
- Formulário de contato
- Navegação entre as seções da página
